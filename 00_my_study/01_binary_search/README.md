## what is uint64_t
### C++ (來自 C 語言的 <cstdint> 函式庫) 中用來精確定義大小的整數型別
u = Unsigned（無號）：代表這個數字沒有負數，只能是 $0$ 或是正整數。<br>
int = Integer（整數）。<br>
64 = 64 bits（64 位元）：代表它在記憶體中佔用 64 個位元（8 個 bytes）。這意味著它可以存儲非常龐大的數字（最大可以到 $18,446,744,073,709,551,615$）。<br>
_t = Type（型別）：這是一個命名慣例，用來告訴開發者「這是一個自定義的型別名稱」，避免跟一般的變數名稱搞混。
